Architecture

L'application utilise une architecture client-serveur :

  • Frontend : HTML, CSS, Bootstrap 5, JavaScript
  • Backend : Python 3.14 avec Flask
  • Base de données : PostgreSQL
  • ORM : SQLAlchemy
  • Messagerie temps réel : Flask-SocketIO

Base de données

La base de données contient 11 tables :

TableDescription
utilisateursComptes et profils des utilisateurs

matchingsPaires mentor-mentoré avec score
conversationsConversations de messagerie
messagesMessages échangés

Algorithme de matching

L'algorithme calcule un score de compatibilité basé sur :

  • Même filière → +40 points
  • Même niveau d'études → +30 points
  • Annonces actives → +30 points

4. Instructions de déploiement

Prérequis

  • Python 3.14+
  • PostgreSQL 16+
  • Git

Étapes

  1. Cloner le dépôt : 
    git clone https://github.com/Fritzell90/PIL1_2526_54.git
cd PIL1_2526_54
  2. Créer et activer l'environnement virtuel : 
    py -m venv venv
venv\Scripts\activate
  3. Installer les dépendances : 
    pip install flask flask-sqlalchemy psycopg2-binary flask-bcrypt flask-socketio
  4. Créer la base de données PostgreSQL : 
    psql -U postgres -c "CREATE DATABASE ifri_mentorlink;"
psql -U postgres -d ifri_mentorlink -f ifri_mentorlink.sql
  5. Configurer la connexion dans app/__init__.py avec votre mot de passe PostgreSQL
  6. Lancer l'application : 
    py run.py
  7. Ouvrir dans le navigateur : http://127.0.0.1:5000

5. Manuel d'utilisation

🔐 Inscription

  1. Cliquer sur "S'inscrire" sur la page d'accueil
  2. Remplir le formulaire (nom, prénom, email, téléphone, mot de passe)
  3. Choisir sa filière et son niveau d'études
  4. Cliquer sur "Créer mon compte"

🔑 Connexion

  1. Cliquer sur "Connexion"
  2. Entrer son email ou téléphone et mot de passe

📢 Publier une annonce

  1. Dans le tableau de bord, cliquer sur "Publier"
  2. Choisir le type (offre ou demande)
  3. Sélectionner la matière et le format
  4. Cliquer sur "Publier l'annonce"

🤝 Trouver un match

  1. Cliquer sur "Voir les matchs"
  2. Consulter les profils compatibles avec leur score
  3. Cliquer sur "Contacter" pour démarrer une conversation

💬 Messagerie

  1. Cliquer sur "Ouvrir" dans le tableau de bord
  2. Sélectionner une conversation
  3. Taper un message et envoyer
